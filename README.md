# KinyarwandaLearn - Full Starter

## Requirements
- Node.js 18+
- MySQL 8+

## 1. Database
Run `database/schema.sql` in MySQL.

## 2. Backend
cd backend
npm install
copy .env.example .env
npm run dev

## 3. Frontend
Open a second terminal:
cd frontend
npm install
npm run dev

Open the Vite URL shown in the terminal, usually http://localhost:5173

Backend API: http://localhost:5000/api/health

## Pages
Home, Learn, Lessons, Quizzes, Progress, Dictionary, Translation, Tutors, Forum, Free Resources, Pricing, Contact, Login, Register, Admin Dashboard.
